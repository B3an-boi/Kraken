🐙 Connect kraken to GMGN

kraken reads live market data with your own GMGN API key. It takes about two minutes, and your keys stay on this computer.

1

Install gmgn-cli

Checking…

2

Create your API key on GMGN

Log in to GMGN in your browser first. The button opens GMGN's "create API key" page with your key already filled in. Click create, then copy the API key it shows you.

Want real trading later? Your GMGN account needs a wallet set up and funded. Everything else works without one.
